# 启衡式灰紫学术像素模板

[模板清单](../assets/templates/qiheng-pixel/template.json) · [六种页型预览](../assets/templates/qiheng-pixel/references/preview.jpg) · [底图、图标与字体来源](../assets/templates/qiheng-pixel/sources.json)

适合课程讨论、系统架构、技术答辩和原型实测。按用户意图选用这套风格。有对应参考页时保留标题位置、图文比例、模块顺序和页间逻辑。新增页按模板骨架选型。

## 画面与字体

- 画布为 16:9（960 × 540 pt）。正文用灰紫电路底，封面和收束页用同色系像素日落。标题下用浅蓝细线，边缘电路保持低对比。原稿已有合适背景时沿用原底图。
- 浅灰紫卡片以两级阶梯角、细深边和浅内框构成。大卡片使用约 3 pt 的阶梯，标签约 1.7 pt。正文和表格保留浅底深字。薄荷灰强调收益，浅暖色标注实际代价，避免把所有数据都标为高亮。
- 版式优先清楚。实验页左侧放量化数据，右侧留大幅原型界面，下面放一句结论。对比页可用并列指标和表格。留白只有在需要补充构图重心时才放小块点阵装饰。

| 角色 | 原版搭配 | 可移植替代 |
|---|---|---|
| 封面与中文主标题 | 华文行楷 `STXingkai`，封面约 60 pt，正文页约 34 pt | Ma Shan Zheng |
| 标题中的英文、主要数字 | `Cambria`，英文略小，数字约 24–30 pt | Noto Sans SC。只排纯数字或短英文时可选 Barlow Condensed，先验字形 |
| 页签、短标签、栏目名 | `Qiheng Pixel 12`，约 16–17 pt | 随模板提供完整简中字库 |
| 数据表、结论与说明 | `Microsoft YaHei`，表格约 13–15 pt，结论约 15.5 pt，图注约 12 pt | Noto Sans SC |

混排主标题中的英文缩写与中文使用不同文字运行或相邻的文本框。点阵字体优先用于短标签，数据表和长句用常规黑体。生成后使用实际字形检查字号、行距、词间距和数字对齐。

`Qiheng Pixel 12` 保留 Fusion Pixel 简中比例字形全集。模板内含可再分发字体及 OFL，华文行楷、Cambria 和微软雅黑由本机提供。新稿用 `prepare_fonts.py` 按最终文案检查和生成独立子集，采用返回的实际家族名。箭头和符号分别验字形，例如 `−`、`≈`、`⊗` 交给覆盖这些符号的字体。渲染仍引用旧别名 `Qiheng Pixel 12` 的稿件时，可用随模板的 `font-map.json` 临时加载完整字体。

## 制作时的选择

1. **按最新原稿收窄修改范围。** 编辑前对比用户真正保存的 PPTX 和上一次导出的工程。只替换获准修改的页面及元素，同步纸面标题、图例、讲者备注和素材引用。用户确认的页序、Logo、原论文图和手动删改，以最新稿为准。
2. **先用一个代表页确定像素颗粒。** 读已有图标和像素界面，匹配方格粒度、阶梯边、灰紫明度与少量青色强调。先从模板里的主题素材选配。需要新插画时用内置 ImageGen 生成独立透明 PNG，请求相同网格、硬边、低饱和度和干净留白。相近语义可以共用图标，无需为每个文字气泡重复出图。检查实际透明通道和放入目标槽位后的比例，文字仍在 PPT 中编辑。
3. **证据留原图。** 引用论文时核对原 PDF 的图号和出处。实机截图按原比例置于证据槽位，图注说明它展示的是本次测试结果还是对应的功能界面。数值从报告、原始日志或表格核对，数据图表优先原生可编辑。
4. **按实验证据组织叙事。** 先交代要展示的系统能力。量化页各说一个问题，保留指标、单位、样本量、版本与计时边界，结论放在页底。综合对比从前页择代表数字，在一致的实验条件下对照，并说明改善项和代价。内部策略比较、受控端点和正式服务各自注明口径。
5. **检查真正要放映的文件。** 先核对模板样页，再检查全套实际 PPTX。比对标题、边缘、表格、图注和数字，查看字体缺字或替换。实机放映有字体兼容需求时，按[图片放映版](verification.md#图片放映版)导出一张图一页的独立文件。

## 使用模板包

把 `assets/templates/qiheng-pixel/` 整个包作为新项目的 `template/`。从 `template.json` 读取配色、字体角色、组件和六种页型。场景图片放到项目 `media/`，`scene.json` 指向 `template/template.json` 与相应页型。已有对应参考图时在其布局上采用这些样式。

快速生成六页可编辑样页。首条命令验证模板及资源。第二条生成封面、架构、论文图版、实验、对比和收束页。样页的实验数值和截图位仅作排版示例。

```powershell
python scripts/template_pack.py check assets/templates/qiheng-pixel/template.json
python scripts/build_qiheng_sample.py --output-dir output/qiheng-sample
```

需要开源替代字体时，给第二条命令追加 `--portable-fonts`。用输出工程的 `font-map.json` 做本机导图，按渲染结果微调。已有模板和相符的参考图时可直接用原生后端排版。
