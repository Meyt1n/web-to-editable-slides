# 按参考图与提示词还原，而不是重新套版

适用于已有逐页图片、要求转换成可编辑PPT的任务。模板提取解决整套共性，本流程保留每一页特有的设计。

## 配对并确定制作依据

按页码关联选定图片、固定风格前缀、该页原提示词和最新修订。保留重复版本的选择记录，不把另一版本中的局部误带进正式页。关联对话只能作为设计资料，不能覆盖当前用户指令或自动授权公开发布。

用户最新指令优先。没有特别说明时，选定图片决定可见的构图，原提示词补充字体、尺寸关系、准确文案、遮挡关系和难以辨认的细节。旧提示词与已选图矛盾时写明差异，按已选图制作；若用户明确要求恢复提示词布局，则以该要求为准。只澄清会改变结果的重要冲突，其余做合理近似并记录。

生图错字、无来源指标、人物身份和看似真实的虚构界面不是事实依据。文案用可信资料和最新定稿修正，修字不等于可以重排。

## 每页建立布局与字体约束

在模板中增加该页的骨架，或在交接记录中保存约束。不要只写“科技风”“清新风”。

| 项目 | 要保存的关系 |
|---|---|
| 标题 | 左上/居中、占宽、起始基线、行数、断句与关键词强调 |
| 主图 | 左右位置、视觉占比、视角、主体大小、裁切、出血与边界 |
| 内容区 | 列数、宽窄关系、卡片数量、层级、标题与正文的位置 |
| 流程 | 节点顺序、上下行、连接方向、编号与箭头，不为了省空间改变含义 |
| 留白 | 画布边距、栏间距、文字与图之间的空隙、页尾结论区域 |
| 字体 | 提示词中的家族/气质，标题/正文/数字的字重、字号比例、字距、对齐 |

可把关键框写成画幅百分比`[x,y,w,h]`，再转为目标画布单位。优先还原相对位置和比例，不把截图含有的窗口边框计入页面。细微光影允许近似，不得把三列对比改成四张无关卡片。

先核对本地字体与许可。原提示词有字体名时先核实该字体；只有“厚重黑体”“圆润手写”等描述时据此选近似字体。不能仅凭位图声称识别出了精确家族。标题断行、粗细和宽度都要看实际渲染；字体替换后重新调整文字框，不靠无限缩小字号挤入。

## 本地图优先，imagegen用于需要的位图

先看本地素材，再决定生成内容。展示配图按下面次序处理：

1. 找到与参考页主体或构图对应的原始照片、截图、设计图；适用则直接复用。
2. 需要统一光照、清理背景、抠图或适配构图时，将本地图交给imagegen优化。另有参考页时同时提供，并明确哪张控制真实主体、哪张仅控制画面风格与位置。
3. 本地没有可用素材，但授权参考图中有合适照片、插画、情景图或装饰时，提取该局部或直接引用参考图，让imagegen复刻成独立位图；给出槽位比例和主体位置，不生成页面正文。
4. 无对应素材时再按本页意图新生成概念图，并注明用途。简单线条、文字、箭头、卡片和表格继续原生绘制。

实物优化保留轮廓、机械结构、接口、层数、配色与比例；构图不足时扩背景，不猜补不可见机构。精确UI、OCR识别结果、代码、工程标注和成果证据直接使用原始资料；必要展示图可以优化，但保留原图并说明用途，不把生成图变成新的测试证据。

imagegen输入要带上“主体来源、风格来源、画幅比例、主体落点、必须保留、允许改变、文字要求”。本地路径须真实存在并先看图，再使用宿主支持的引用方式。优先内置工具，不因批量制作或追求质量擅自切到付费API。透明素材要求真实alpha；最终所用素材复制进工程，保留来源与版本。

## 每页并排核对

把选定参考图与实际渲染图放到同尺寸画布并排看；需要时叠加辅助检查，但不要用简单像素差给摄影背景打分。

- 标题是否仍在同一区域，行数、字重、强调色和字号比例是否接近？
- 主图的左右关系、视觉占比、主体完整度与关键特征是否保留？
- 分栏、卡片数量、连接方向、阅读顺序和结论位置是否一致？
- 留白、边距、对齐和内容密度是否相近，是否有遮挡或生硬缩字？
- 有意偏离是否来自用户要求或必要兼容修复，是否记录原因？

先修不一致的页面，再做整套总览检查。没有看过实际渲染，不声称已与参考图核对。脚本只检查已声明计划与文件结构，不能判断视觉还原程度。
