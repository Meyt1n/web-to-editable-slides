# 旧纸剪贴簿 · 访谈与社会实践

适合社会实践、家乡调研、口述史和现场走访。版式依据用户定稿《从家庭作坊到产业升级》的实际导图及原生文本。重建时预留的空相框与用户补入照片后的定稿分别提供了两个制作阶段的依据。需要现成骨架时读取 [模板参数](../assets/templates/fieldwork-scrapbook/template.json) 和 [通用样片](../assets/templates/fieldwork-scrapbook/references/preview.jpg)。

## 画面和字体

- 960 × 540 画布。浅暖旧纸为基底，远景和朱红布纹压在下沿。封面可用较完整的湖景，正文使用窄远景。复杂纸纹和远景用无字底图，撕边纸、胶带、题字、箭头和线稿放在独立图层。
- 标题取深朱红 `#840E08`，笔刷色 `#A52B1F`，正文取墨棕 `#32180B`。内容纸 `#FFEFD6`，相纸 `#FFF5DF`，图标和小线条用棕色。[素材来源](../assets/templates/fieldwork-scrapbook/sources.json)
- 封面和结尾主标题可以在边缘留出的区间内放大。正文页通常从 40 pt 开始，栏目用 23 pt，正文约 17 pt。小标题要放得进红色笔刷，手写图注应短。长引语可以用浅纸宋体并设置明确断行。

| 角色 | 可随项目交付的字体 | 定稿用法 |
|---|---|---|
| 封面主标题 | Ma Shan Zheng（马善政），依据标题长度调整字号或分行 | 定稿在封面使用华文行楷（STXingkai），约 60 pt |
| 正文页标题、栏目条 | Ma Shan Zheng | 深朱红大标题，红底浅字栏目 |
| 正文和问句 | Noto Serif SC，冻结到 600 | 宋体保证正文的辨识度 |
| 图注和短批注 | Long Cang（龙藏） | 手写感用于少量短标签 |
| 年份章 | Barlow Condensed | 纯数字与短西文用窄体，带中文单位时按原稿用毛笔或拆分字体角色 |
| 结尾大字 | Ma Shan Zheng | 定稿结尾大字及引言用华文新魏（STXinwei），大字约 125 pt |

若任务明确要求华文行楷或华文新魏，先确认目标 Windows 机有对应字体，再将其作为 `system_font` 声明，用实际导图检查宽度和大小。Skill 随附的字库采用表中的开源搭配。新稿用完整字库检查所用字符，按本次文案重做子集。旧稿的内部家族别名和已交付的字体子集只服务原稿。

## 版式按内容选

| 页型 | 结构 |
|---|---|
| `cover` | 居中主题与副标题，左右三张斜相框，湖景下方留落款 |
| `origin` | 左侧缘起和疑问，右侧资料查阅、人物访谈、现场走访三张错位照片 |
| `interview` | 上方一条提问，左侧主证据图，右侧打孔纸回答与时间线，底部一句发现 |
| `process` | 左侧三张过程照片和标签，右侧用连线说明阶段关系 |
| `comparison` | 年份印章加前后对照，相近比例的证据图配同口径说明 |
| `change-details` | 左侧一大两小的证据拼贴，右侧按类别逐行写变化 |
| `field-visit` | 上方三张现场照片，下方并列表述现场观察和公开资料案例 |
| `takeaways` | 三列观点和对应证据，底部用箭头串起关键词 |
| `closing` | 中央主题、结语和短引语，左右相框回顾开头 |

这些页型可单独选用或换序。已有逐页参考稿时，保留原页图框数量、阅读顺序和比例。地点、人物、引语和照片由当前项目资料提供。

## 制作经验

1. 先锁定最新原稿。看 PowerPoint 的实开导图，再查原生字号和字体声明。标题、正文、照片与照片内的原始字幕分别核对。前几轮工程可以提供组件做法，当前定稿决定文案和图片。
2. 先做一页问答或对比样页。原生毛笔字用单独文本框。年份章旁给长标题预留宽度，封面左右相框之间给主标题预留宽度。实开检查尾字、标点、图注与题字的断行。
3. 相框按投影、相纸、图片、胶带、图注叠放。相纸与图片框用同一旋转角度，略厚的下边框要绕相纸中心计算偏移。用户要自行补图时，矩形用 `picturePlaceholder: true`。原稿中已有真实证据时用独立图片。做一次插入或更换实测，确认位置、旋转和裁切，再看人物脸部、纸页文字或产品主体。
4. 把纹理和复杂装饰做成独立无字素材。背景里已有的实拍证据按原资料保留。现场照片、公开资料和生成插画各按来源标注。
5. 字体回退优先从实际播放器定位。用 `font-map.json` 临时加载生成的子集，检查封面、页标题和小注释。需要嵌字时另存副本并再次打开，验证视觉字形和文字宽度。此前曾出现字体部件可读而 PowerPoint `Slide.Export` 回退，封面标题即因此伸进相框。嵌入存在与最终渲染是两项检查。
6. 用户需要导入后保持字形和版式时，另做逐页图片版。旧纸稿曾以 3840 × 2160 导出，9 页均在同尺寸实开复核。每页一张铺满画布的嵌入图，从已确认字形的原稿导图开始。[图片放映版命令](verification.md#图片放映版)

## 实际套用

内置 `template.json` 记录颜色、字体角色、组件与槽位。用 `template_pack.py prepare` 把模板与依赖写入当前项目的 `template/`。参考样片代码中 `ScrapbookPage` 的 `paper`、`brush`、`photo` 和 `notebook`，从所需页型构建自己的 `scene.json`。按项目文案生成字体子集，编译并实开检查最终 PPTX。

```powershell
python scripts/build_scrapbook_sample.py --output-dir output/fieldwork-scrapbook
.\scripts\render_pptx_windows.ps1 -InputPptx output/fieldwork-scrapbook/deck.pptx -OutputDir output/fieldwork-scrapbook-preview -FontMap output/fieldwork-scrapbook/font-map.json
```

样片生成 9 页原生 PPTX 和配套 PPTD。PPTX 可以在相框内部插图。PPTD 保持同样的画面结构，补图可在对应空框位置添加独立图片对象。样片使用 `font-map.json` 指定的字库子集，PowerPoint 加载 `media/fonts/` 中的配套字体后会显示对应字形。套用新文案时按实际用字重新生成子集。向项目传递模板时带上 `template.json` 及其打包依赖。[原生场景字段](native-scene.md)
