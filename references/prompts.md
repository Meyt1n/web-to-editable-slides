# 网页版到可编辑PPT：可直接复制的提示词

花括号中的内容替换为实际项目资料。已有材料时跳过已完成步骤；风格选定后把固定前缀放进每一页提示词，不让模型逐页重设计。

## 1. 最开始发给网页版的完整任务书

先粘贴本段并上传已有材料，缺少的项写“未提供”。已有风格或定稿时删掉重新选型要求；不为了填表编造内容。

```text
你将帮助我把《{作品名称}》做成{用途}PPT。
最终这些参考页会交给另一个能看图、能写文件的模型重建为可编辑PPT。
所以请把内容、整套设计规范和每页排版写清楚，后续能按同一模板还原。

【汇报目标】
受众：{受众及了解程度}；场景：{现场投影/阅读提交/产品展示}。
预计{页数}页、讲解约{时长}；画幅{16:9或指定画幅}。
看完希望观众理解：{核心问题、作品价值、最有说服力的成果}。
语气：{专业/亲和/叙事等}；不出现：{禁止的人名、单位、其他项目名称等}。

【作品事实】
1. 要解决什么：{真实问题、使用场景、目标用户}。
2. 产品是什么：{形态、边界、核心功能}。
3. 如何使用：{输入、关键步骤、输出、异常或限制}。
4. 如何实现：{真实技术栈、结构、软硬件分工及信息流}。
5. 已有成果：{可运行程序、原型、实拍、真实界面、运行视频}。
6. 实际创新：{自主完成部分、与已有做法的差异、证据}。
7. 验证状态：{已测内容、真实条件与结果、仍需完善之处}。
8. 后续设想：{尚未实现的方向，单独标记}。
不确定内容：{列出或写未提供}。

【附件与素材】
附件清单：{文件名—内容—用途—事实状态}。
请实际看图，识别设备外形、界面和关键细节；文字资料用来核对名称与功能。
真实成果页优先实拍与真实截图，不能拿生成图代替实际成果。
展示配图若需优化，后续将优先用本地图作为imagegen输入，保留实物形态。
允许生成：{环境、概念场景、独立插画、无字背景等}。
必须原样保留：{设备机构、接口、Logo或指定界面等}。

【设计方向】
已有参考图/风格：{附图及我选择的版本；未选则写未选}。
偏好：{主色、强调色、氛围、图片质感、明确不喜欢的表现}。
字体要求：{指定字体或标题/正文/数字的气质；不确定可给候选}。
风格未选时，先用同一页做少量不同方向供我选；已选时直接沿用。
选定后建立统一规范：字体角色、字重、字号比例、颜色、网格、边距、组件和图片处理。
允许多种页型，保持同一设计语言；不要每页随意换字体或背景。

【请依次交付】
第一步：整理事实与素材索引，区分已实现、演示数据、概念图、正在完善和未来设想。
只提出真正影响制作且资料无法回答的问题，先完成其余部分。
第二步：给逐页大纲，每页一个重点，写标题、关键文案、证据、配图用途和布局意图。
第三步：确定视觉方向，输出统一模板规范与少量代表页的设计。
第四步：写固定视觉前缀和逐页生图提示词，供我逐页调用，不自行一次生成全部。
每页提示词必须说明标题、分栏/卡片数量、图文区域、阅读顺序、字体层级和留白。
第五步：后续逐页生图时，始终引用选定模板与对应页提示词。
如生成图与提示词偏离，记录差异；不要将错字当作正确文案延续。

不要补造性能指标、用户测试、实物结构、身份或获奖情况。
先从第一步开始；我已明确完成的阶段直接跳过。
```

## 2. 网页版生成大纲

```text
基于刚才确认的事实清单，写一份{N}页PPT大纲。
每页列：页码、标题、该页要表达的重点、准确文案、建议配图、事实来源、建议布局和阅读密度。
布局写清列数、图文左右位置、信息主次和流程方向，避免只写“大气美观”。
先让观众理解问题、用户和产品定位，再讲设计、技术、交互、成果与后续方向。
同一个意思避免在相邻页反复写。页数不足时合并，不能用未经证实的数据凑页。
```

## 3. 生成少量风格候选

```text
保持大纲不变，给出3种有明显区别的视觉方向。
每种说明主色、强调色、字体气质、背景、图片处理、卡片与流程形式。
用同一页内容生成候选图，方便直接比较设计，而不是比较不同文案。
优先考虑投影阅读的清晰度，为标题、正文和实物图留下足够空间。
```

风格选择是有实际分歧的节点；用户已选风格时直接复用，不重复询问。

## 4. 确认风格，写统一前缀和逐页提示词

```text
采用{已选风格}。请输出一个固定的视觉规范前缀，再为每页写独立提示词。
固定规范包含：16:9、颜色、标题/正文/数字/点缀的字体角色、层级、页边距和图片处理。
先按主题比较少量字体搭配，例如宋体标题＋黑体正文，或亲和短标题＋清晰正文，再固定一组。
每页提示词包含：准确标题和正文、标题行数与断句、布局列数、卡片数量、元素位置与相对占比、阅读顺序、配图用途、必要留白。
字体分别写家族或可识别气质、字重、字号比例、颜色、对齐及关键词强调；位图生图不能保证精确家族，后续重建再核实字体。
位置可用画幅百分比说明，例如左文约40%、右图约52%，间隔约4%，只在适合该页时使用。
在同一设计语言中交替使用大图、开放分栏、对比、过程、架构、证据或章节留白；内容不需要时不凑页型。
真实产品外观按附件保留；概念场景与实物证据分开标明。
全文保持同一套设计语言，不新增人名、学校、赛事、无来源指标或品牌。
```

## 5. 网页版逐页生图

```text
使用下面的固定风格和本页提示词，只生成第{页码}页。
这是一张PPT视觉参考稿，画幅16:9，内容不得裁掉。
固定风格：{前缀}。
本页内容与布局：{逐页提示词}。
参考前一张已确认页面的配色与字体层级，保留本页提示词约定的分栏、主图位置、节点数量和留白。
```

每张命名为 `01_cover.png`、`02_contents.png` 等。重复版本写 `09_mechanism_v2.png`；移交时说明选哪版。不要把图上生成的错字当作后续正文来源。

## 6. 移交给能看图和写文件的模型

```text
使用 $web-to-editable-slides。
这些图片是我在网页版生成的PPT参考稿，提示词在我提供的关联对话或文字导出中。
按附件顺序做成{N}页真正可编辑的PPT，重复版本{处理方式}。
先将每页图片与原提示词配对，提取共性落成模板，再记录每页的布局和字体约束。
已有参考的页面遵守原图标题位置、图文比例、列数、卡片数量、流程方向与留白。
结合原提示词的字体家族或气质、字重、字号比例、强调与断行，不只模仿配色。
先查{素材目录}并看图；展示配图需要改善时，优先用本地图作为imagegen输入优化。
本地没有合适图片时，可对参考图中的授权图片局部用imagegen复刻，生成独立素材。
真实界面、工程图和成果证据保留原图；标题、正文等不烘焙进生图。
标题、正文、编号、流程和表格用原生对象，图片保持独立且不拉伸。
保留{风格}，不新增未经验证的功能、数据或身份信息。
每页实际导图后与对应参考图并排检查，修正位置、比例、字体和裁切，再交付PPTX、预览和完整源工程。
```

宿主的关联对话功能不可用时，附上大纲、固定风格、逐页提示词即可。继续处理已知内容，只追问真正影响制作的缺项。

## 7. 生成可复用的无字母版

```text
为{主题}制作一张16:9演示文稿背景。
沿用参考图的{主色、强调色、光照、材质和环境}。
只保留边缘环境、自然光和少量装饰；中央与{标题区}大面积留白。
无文字、无数字、无水印、无Logo，不生成完整信息图或正文卡片。
这张图将作为底层位图，标题和结构会在PPT中用原生元素添加。
```

## 7a. 从提示图提取一套模板

```text
先不要批量制作正文页。请从我提供的整套PPT提示图中提取一套可复用模板。
选封面、章节、正文、流程等代表图，记录共性的配色、字体角色、网格、间距、卡片、编号、箭头与图片处理。
同时读取对应提示词，把其布局与字体要求和可见图片核对，记录差异与选定依据。
除整套共性外，保留逐页骨架；不能让通用模板改变已有参考页的列数或图文关系。
把固定规范与本页文案、产品照片、数据等可替换内容分开。
输出实际可读取的模板包：模板ID/版本、设计参数、原生组件样式、页型骨架、必要背景与字体许可、来源说明。
如需位图母版，可用imagegen根据参考图共性生成无字背景；不要直接拿带字参考页当背景。
先按模板做一个代表页并对照提示图检查。已有确认风格时自行核对，明显冲突再说明具体问题。
```

## 7b. 根据已经提取的模板设计后续页

```text
读取刚才的模板包，后续页面全部绑定同一模板ID和版本。
每页先选模板页型与内容槽位，再填入文字和独立素材；持续使用模板里的字体、颜色、网格和组件。
已有逐页参考时保留对应页的布局骨架与字体关系；只有无对应参考或我允许重排时，才在模板范围内另选结构。
不逐页重猜字体或重新生成互不相关的背景。
需要新结构时先扩展模板变体；必须偏离规范时写清原因。
交付前同时检查内容、模板一致性和实际渲染，给我模板包、设计计划、可编辑PPT与源工程。
```

## 8. 用实物图优化配图

```text
基于附件中的真实设备照片，只清理背景、调整光照和清晰度，生成独立主体素材。
保留产品轮廓、机构、接口、层数、颜色和比例，不补造屏幕、结构或功能。
完整保留主体边缘；若要求透明背景，输出真实透明通道。
用途是汇报中的设备展示，原始照片另行保留以供核对。
```

### 8a. 本地图保留主体，参考页控制构图

```text
输入图1是本地真实主体照片，是外形与结构的依据。
输入图2是PPT参考页，只参考其中{指定区域}的构图、背景、光照和色彩。
请把图1优化成适合{宽高比}槽位的独立配图，主体位于{左/中/右及占比}。
保留图1的轮廓、机构、接口、层数、配色与比例；只优化背景、光照和清晰度。
不从图2复制另一设备的结构，不补造功能；缺少的空间扩展背景。
不要包含PPT标题、说明、编号和图表；{透明背景/无字场景背景}。
```

### 8b. 本地缺图时，复刻参考页中的图片局部

```text
请参照输入图中{明确局部位置}的{照片/插画/装饰}，复刻成独立位图素材。
保留该局部的主体、视角、构图、色彩和光照，适配{宽高比}，主体位于{位置}。
不复制整页PPT，不包含周围标题、正文、卡片和流程箭头；这些会在PPT中原生重建。
输出用途是{概念场景/展示插画}，不将其作为实拍或性能验证。
{需要透明背景时：保留完整主体和真实透明通道。}
```

精确UI、工程图和结果证据使用原始资料。局部可用原始输入或宿主支持的裁图工具交给imagegen，不为了复刻图片而把页面文字一起烘焙进去。

## 9. 小步修订与增页

```text
只修改第{页码}页的{具体问题}，沿用已确认的风格和其余内容，另存修订版。
```

```text
按现有总目录制作{章节数}张独立章节页。
章节名称与副标题以最新目录为准，标题与编号可编辑。
沿用现有背景、字体和强调色，交付独立PPT供我插入。
```

## 10. 公开示例另换主题

```text
把制作方法封装开源。公开资料不用我的真实图片、作品名、APP界面、私有对话或本机路径。
换成虚构主题，用imagegen新生成参考图、无字背景与主体素材，标明概念演示。
文档写方法、工具、限制和可运行脚本；引用私人资料的地方改为通用交接字段。
```

## 11. 同风格优化字体与排版

```text
继续使用已经确认的主题和配色，在原风格内优化这套PPT。
先给标题、正文、数字和少量点缀明确字体分工，比较适合主题的少量搭配后选定一组。
保持字体角色稳定，通过字重、字号、图文比例、对齐、分栏和留白增加表现。
按每页内容选择结构：比较用并置/矩阵、过程用路径/泳道、原型用大图标注、成果用证据与说明。
检查整套缩略图，改善不必要的连续卡片重复，安排有理由的密度或明暗变化。
不要为追求丰富编造数据、改变作品事实，或把正文做成无法编辑的生图文字。
只修改允许调整的部分，给我设计计划、实际预览和可编辑文件。
```
