# 网页版到可编辑PPT：可直接复制的提示词

花括号中的内容替换为实际项目资料。已有材料时跳过已完成步骤；风格选定后把固定前缀放进每一页提示词，不让模型逐页重设计。

## 1. 先讲清楚作品

```text
我准备制作《{作品名称}》的{用途}PPT。
受众：{受众}；预计{页数或时长}；希望讲清楚{核心问题}。
作品资料如下：{实际功能、实现方式、使用过程、现有成果}。
附件包含：{文档、实物图、界面截图、演示视频、模型或工程图}。
请先整理事实清单，区分已实现、正在完善、演示数据和未来设想。
不要补造性能指标、试用结论、实物结构、人物身份或获奖情况。
再列出影响PPT内容、但现有资料无法回答的问题。
```

## 2. 网页版生成大纲

```text
基于刚才确认的事实清单，写一份{N}页PPT大纲。
每页列：页码、标题、该页要表达的重点、正文要点、建议配图、事实来源。
先让观众理解问题、用户和产品定位，再讲设计、技术、交互、成果与后续方向。
同一个意思避免在相邻页反复写。页数不足时合并，不能用未经证实的数据凑页。
```

## 3. 生成少量风格候选

```text
保持大纲不变，给出3种有明显区别的视觉方向。
每种说明主色、强调色、字体气质、背景、图片处理、卡片与流程形式。
用同一页内容生成候选图，方便直接比较设计，而不是比较不同文案。
优先考虑投影阅读的清晰度，为标题、正文和实物图留下足够空间。
```

风格选择是有实际分歧的节点；用户已选风格时直接复用，不重复询问。

## 4. 确认风格，写统一前缀和逐页提示词

```text
采用{已选风格}。请输出一个固定的视觉规范前缀，再为每页写独立提示词。
固定规范包含：16:9、颜色、标题/正文层级、页边距、卡片、图片与装饰。
每页提示词包含：准确标题和正文、元素位置、主次关系、配图用途、必要留白。
真实产品外观按附件保留；概念场景与实物证据分开标明。
全文保持同一套设计语言，不新增人名、学校、赛事、无来源指标或品牌。
```

## 5. 网页版逐页生图

```text
使用下面的固定风格和本页提示词，只生成第{页码}页。
这是一张PPT视觉参考稿，画幅16:9，内容不得裁掉。
固定风格：{前缀}。
本页内容与布局：{逐页提示词}。
参考前一张已确认页面的配色与字体层级，保留本页的合理留白。
```

每张命名为 `01_cover.png`、`02_contents.png` 等。重复版本写 `09_mechanism_v2.png`；移交时说明选哪版。不要把图上生成的错字当作后续正文来源。

## 6. 移交给能看图和写文件的模型

```text
使用 $web-to-editable-slides。
这些图片是我在网页版生成的PPT参考稿，提示词在我提供的关联对话或文字导出中。
按附件顺序做成{N}页真正可编辑的PPT，重复版本{处理方式}。
提取整套图片的共性，必要时用imagegen生成无字模板和独立素材。
优先使用{素材目录}中的实物图、真实界面和工程图；可基于实物做背景与光照优化。
标题、正文、编号、流程和表格用原生对象，图片保持独立且不拉伸。
保留{风格}，不新增未经验证的功能、数据或身份信息。
先逐页看图检查，再交付PPTX、预览和完整源工程。
```

宿主的关联对话功能不可用时，附上大纲、固定风格、逐页提示词即可。继续处理已知内容，只追问真正影响制作的缺项。

## 7. 生成可复用的无字母版

```text
为{主题}制作一张16:9演示文稿背景。
沿用参考图的{主色、强调色、光照、材质和环境}。
只保留边缘环境、自然光和少量装饰；中央与{标题区}大面积留白。
无文字、无数字、无水印、无Logo，不生成完整信息图或正文卡片。
这张图将作为底层位图，标题和结构会在PPT中用原生元素添加。
```

## 8. 用实物图优化配图

```text
基于附件中的真实设备照片，只清理背景、调整光照和清晰度，生成独立主体素材。
保留产品轮廓、机构、接口、层数、颜色和比例，不补造屏幕、结构或功能。
完整保留主体边缘；若要求透明背景，输出真实透明通道。
用途是汇报中的设备展示，原始照片另行保留以供核对。
```

## 9. 小步修订与增页

```text
只修改第{页码}页的{具体问题}，沿用已确认的风格和其余内容，另存修订版。
```

```text
按现有总目录制作{章节数}张独立章节页。
章节名称与副标题以最新目录为准，标题与编号可编辑。
沿用现有背景、字体和强调色，交付独立PPT供我插入。
```

## 10. 公开示例另换主题

```text
把制作方法封装开源。公开资料不用我的真实图片、作品名、APP界面、私有对话或本机路径。
换成虚构主题，用imagegen新生成参考图、无字背景与主体素材，标明概念演示。
文档写方法、工具、限制和可运行脚本；引用私人资料的地方改为通用交接字段。
```
