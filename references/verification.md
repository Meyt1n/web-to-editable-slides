# 从“可打开”检查到“可编辑、可阅读”

## 每页先看图

查看缩略总览确认风格、密度和章节顺序，再放大检查正文、脸部/产品遮挡、边界、裁切、换行和对齐。页面越密集，越要在真正使用的字体和目标软件中渲染。

已有逐页参考时，将实际渲染与对应选定图并排核对，按[逐页还原清单](reference-fidelity.md)检查位置、占比、列数、卡片数量、阅读顺序、字体气质和标题断行；同时对照原提示词中的字体与布局要求。只看成品自身是否整齐不足以证明还原成功。必要近似或授权变更写明原因，布局相似性由实际看图判断，不让结构脚本冒充视觉评分。

PPTD生产时，使用所属演示文稿技能的图片导出工具先检查源工程；导出PPTX后另在PowerPoint或可用播放器中实开。不要仅凭ZIP检查通过就声称WPS、Keynote和PowerPoint完全一致。

## 检查可编辑性

```bash
python scripts/check_pptx.py path/to/deck.pptx --output output/report.json
```

脚本按演示顺序报告每页原生文字框、含文字的原生表格单元格（`editable_table_cells`）、形状、图片和表格，并标出“有图片、无非空原生文字”的页面。表格中的文字也计入原生文字判断，避免把带表格的图片页误报为整页截图。这只是图片页提示：照片页可能合理，含大量文字的整页截图则需要重建。

进一步在软件中点选标题、编号、正文和流程节点。复杂插画保留为独立图片是合理的；不把背景全图上的文字计作可编辑正文。

## 字体

- 先确认字体来源和再分发许可；许可文件随素材交付。
- 可读性优先于完全相同的字形。目标机没有字体时，使用允许嵌入的字体，或选可接受的替代字体。
- PPTX里出现`ppt/fonts/*`不等于字体已嵌入。脚本核对`embeddedFontLst`声明、内部字体关系与实际资源，以`embedded`记录是否被声明引用；孤立文件会警告，不能满足`--require-fonts`。
- `recognized_header`只表示识别到格式头，`valid_binary`表示可解析字体表。脚本可解析TTF/OTF/TTC，以及未压缩或XOR处理的EOT；伪造文件头、缺损字体表和HTML不能通过严格检查。
- 压缩EOT、未知或混淆格式会标为“无法验证”，使`--require-fonts`返回失败；这不等于字体损坏。仓库预制示例含压缩EOT，普通结构检查仍可通过并给出警告，需用目标播放器实际确认。即使`valid_binary`通过，也不证明字符覆盖、嵌入许可或跨软件播放一致。
- 某些字体在本机未安装时，Office导出仍会替换字形。安装字体是对用户环境的修改，按用户范围处理；不要在通用脚本里偷偷安装。
- 示例构建器默认只声明字体，不自动安装或嵌入。可选的`embed_fonts_windows.ps1`调用本机PowerPoint保存字体；先自行安装示例OFL字体，保存后用`--require-fonts`验证。
- 新主题试跑及本地字体导图见[生产试跑](production-test.md)。嵌字脚本可显式传`-FontMap`临时注册已授权字体，结束即撤销；实际结果仍以最终PPTX实开为准。

## 切换

`--require-fade`检查每页有一个根级`p:transition/p:fade`，并位于`cSld`、可选`clrMapOvr`之后，以及`timing/extLst`之前。把`p:fade`嵌在页面内容树里，Office可能忽略。

只有用户要求、或确实适合现场展示时，才安排逐元素动画；页面淡入淡出与元素动画是两种设置。用户不需要切换时不要强加。

每页`animations`报告现在记录实际时序、触发和时长，并拒绝指向已删除对象的动画。静态导图只显示终态，不能验证出现次序；用PowerPoint播放或`render_animation_windows.ps1`导出动态预览，再核对问答点击组。背景与动画的组合方法见[设计表达](art-direction.md)。

需要完整编排信息时用`inspect_design.py`读取点击组与显式时序，包括没有`animEffect`过滤器的飞入、缩放与放大复位。静态导图也不等于含退出动画的最终播放状态。对原生稿执行嵌字或另存后，运行`check_motion.py 原始.pptx 另存.pptx --output motion-preservation.json`；自动流程`finish`已接入比对。点击组、目标、效果或时序改变时先修复，再交付；比对不证明视觉效果或跨软件兼容。具体方法与一次被PowerPoint吞掉强调动画的修复见[动画选型](motion-design.md#必须检查运动过程)。

## 常见导出问题与窄修复

| 现象 | 处理 |
|---|---|
| 图标变成圆点/空白 | 保留SVG源，转成独立PNG再导出；核对图标许可 |
| 中文日志乱码 | 用UTF-8脚本和运行模式；不要修改系统区域设置来修单个项目 |
| 字体嵌入的是很小的文件 | 检查是否下载了错误页；重新用真实字体保存并检查二进制 |
| 本地导出找不到YAML模块 | 先检查项目Node/Python依赖；按后端文档设置依赖路径，避免改全局配置 |
| 浏览器导出弹窗卡住 | 先读错误并按后端文档重试；有本地导出路径时使用它，不循环盲点 |
| 数字或大标题越框 | 看真实字体渲染结果，扩大框或降低字号，再重新导图 |
| 页面改过但源工程是旧稿 | 以用户最新文件为准，只在新副本中改；避免旧源重建覆盖用户修改 |
