# 手写讲稿的质感与书写顺序

适用于现场讲解、课堂或用户明确选择的手写风。参考稿只用于学习方法；不修改原件，不把其文字、纸纹、图片字或讲稿收入公共素材库。聊天截图说明设计意图，文件结构和实际PowerPoint播放说明实现方式。

## 先区分外观与对象

一次实测参考由纸纹JPEG、透明词图、独立线段图和分组擦入构成。文件没有原生正文或嵌入字体，不能从图片恢复并断言原字体名称。词图可移动、裁切和播放动画，文字内容不能直接修改。视觉近似、文字编辑、原生图形编辑分别记录。

后续默认保留可编辑文字：按词或短语拆成原生文本框，图表和关系图继续原生。只有明确选择视觉固化时，才把文字转图，并同时保留文案、词序、字号、坐标与源字体映射。不要因“避免换机字体问题”自动把整套文字转成图片；先准备有许可、覆盖实际文案的字体并嵌入。

## 外观中值得保留的关系

- **纸张**：暖白底、很浅的纤维与细点，内容区保持干净；纹理只增加近看质感，不降低投影对比。可先用imagegen生成独立无字纸纹背景。参考中估计的纸白约为`#FBF7EF`，只是该套稿的取色依据。
- **字与线**：深墨正文、细笔手写气质，笔画轻微变化，保持清楚的基线与阅读顺序；不要把字母、角度或粗细扰动放大成排版噪声。字库名称需有文件或来源证据，位图外观只支持近似选型。
- **色彩分工**：蓝色连接、推导与下划线；酒红结论框或关键判断；绿色成立条件；少量黄色标出关键词。按内容角色固定，不为凑颜色反复强调。
- **版面**：讲解页围绕一个问题组织，图形与文字共同解释，空白留给后续展开。省去不承担导航的卡片、阴影和装饰；文字与线条的最终粗细以真实投影尺度核对。

这些关系可迁移，不把参考稿的页数、学校配色、英文手写体或全图文字当成所有主题的要求。

## 先拆对象，再安排时序

1. 文字按阅读单位拆分。英文通常按词，中文通常按短语；长引用和密集表格可以整块淡入，不强迫每个字都慢慢写。
2. 图形按绘制单位拆分：节点框的各条边、连接线、箭头尖、下划线、圈线与排线。复杂弧线可拆成短段；整体矩形擦入不会自动沿曲线前进。
3. 每个知识点一次点击，组内自动依次写出。先出现节点和标签，再画连接线，箭头尖随线尾出现，最后画强调线或结论框。保持底纸静止。
4. 用短停顿表达换词、换笔和结论出现；标题不必把整页信息都等同处理。约2–6秒可作为一组的初始预算，长组先改成短语或拆讲解点，实际节奏由内容决定。

参考文件的擦入时长约64–600毫秒，中位数235毫秒；这是观测参数，不是通用标准。新预设按词长给出约140–380毫秒的起点，可逐单元覆盖时长、方向和停顿。不要用纯随机延迟代替明确的阅读和绘制顺序。

```python
from motion_presets import handwriting_groups

animations = handwriting_groups([
    [
        {"elementId":"term-1", "text":"先观察"},
        {"elementId":"term-2", "text":"再解释"},
        {"elementId":"underline", "direction":"left", "durationMs":280}
    ],
    [
        {"elementId":"node-label", "text":"结论"},
        {"elementId":"arrow-shaft", "direction":"left", "durationMs":320, "gapAfterMs":0},
        {"elementId":"arrow-head", "direction":"down", "durationMs":120}
    ]
])
```

这些ID必须指向已有元素；`text`只帮助估算时长，不生成或替换文字。第一单元触发点击，后续单元使用`afterPrevious`；设置`autoplay=True`用于自动播放探针，知识点之间保留短停顿。与常规同时展开的`reveal_groups`按需要选用。

## 切换与页内动画分别验证

实测参考使用约900毫秒、`byObject`的Morph切换，并通过`mc:AlternateContent`附带fade回退；重复底纸保持同名、同资源和同坐标。不要把两个兼容分支误判为重复切换，也不要因为存在fade回退就宣称首选效果是fade。真正嵌在内容树中的切换仍应报错。

当前原生后端输出fade；选择支持Morph的后端才能精确生成该效果，并须实际验证匹配对象、背景稳定及回退行为。检查器能读取Morph不代表所有后端和播放器都能实现它。

```powershell
python scripts/inspect_design.py reference.pptx --output output/design-analysis.json
./scripts/render_animation_windows.ps1 -InputPptx reference.pptx -OutputVideo output/playback.mp4 -FrameRate 30
```

先检查静态终态，再查看逐词、节点、连接线和结论的中间帧。几十毫秒的短笔画可能被12fps预览跳过，书写节奏宜用30fps或实际放映检查。自动播放视频只能验证渲染与组内次序，现场点击的停顿另行验证；不要把XML延迟估计当作实际播放证明。`inspect_design.py`只计算明确的并行延迟，遇到事件引用或串行时序会保留未解析值。

原生手写字体导视频若出现回退，可传`-FontMap output/deck/font-map.json`临时加载随包字体，结束后自动撤销。原生文字动画和图片词图动画应分别检查，不能用图片文字稿播放正常来证明原生字体也正确。
